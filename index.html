n8n home

n8n home is a private, personal automation used only by its owner, Alastair Clayton. It is not offered to the public.

Privacy Policy

The app connects to the owner's own Google Tasks account so that tasks can be copied into the owner's personal notes on the owner's own computer.

  • Only the owner's own Google account is accessed.
  • Data is stored only on the owner's private computer.
  • No data is shared with, sold to, or sent to anyone else.
  • Google user data is used only to provide this personal feature, in line with the Google API Services User Data Policy, including its Limited Use requirements.
